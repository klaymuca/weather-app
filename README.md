# Weather App

## Description
A simple weather application that allows users to search for a city and view its current weather conditions.

## Technologies Used
- HTML
- CSS
- JavaScript
- Open-Meteo API

## Features
- Search for cities
- Display current temperature
- Display weather descriptions and icons
- Handle invalid cities and empty searches
- Responsive layout

## How to Run
1. Clone the repository.
2. Open `index.html` in a browser.
3. Enter a city name and click Search.
